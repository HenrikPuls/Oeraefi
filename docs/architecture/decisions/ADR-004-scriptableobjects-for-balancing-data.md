# ADR-004: ScriptableObjects for All Balancing Data

Status: Accepted (backfilled from arc42 decision table; decided pre-M0)

## Context

The concept doc defines extensive balancing tables (skill starting values per origin 11.6, Kúgildi price anchors 14.2/14.6, calendar months, thrall provisioning/risk curves 4.5). These are game-design decisions that must stay editable without code changes, and initial values are transcribed from the concept doc by the LLM.

## Decision

All balancing/configuration data lives in ScriptableObject assets under `Assets/Data/` (and module-specific data folders), generated by editor scripts from the concept-doc tables. Code references named constants or assets, never magic numbers.

## Consequences

- Balancing changes require no recompilation and no code review.
- Transcription of concept-doc tables into assets is guarded by table-equality tests.
- The user owns balancing edits (Inspector); agents must not change SO data values autonomously (CLAUDE.md scope rule).
